# Quick Start

## 1. Build the hybrid fork

```bash
git clone https://github.com/Hahyun-Lee/smart-connections-mcp.git
cd smart-connections-mcp
npm ci
npm run build
```

## 2. Add it to your MCP client

```json
{
  "mcpServers": {
    "smart-connections": {
      "command": "node",
      "args": ["/absolute/path/to/smart-connections-mcp/dist/index.js"],
      "env": {
        "SMART_VAULT_PATH": "/absolute/path/to/Vault One,/absolute/path/to/Vault Two",
        "SMART_SEARCH_PROFILE": "adaptive"
      }
    }
  }
}
```

The vault must contain `.smart-env` data generated by the Obsidian Smart
Connections plugin. Use absolute paths. The npm package with the unscoped name
currently installs upstream, not this hybrid fork.

## 3. Restart and test

Restart the MCP client completely, then ask it to call `get_stats` and
`search_notes`. The search response should say `"profile": "adaptive"` and each
hybrid result should name its `retrieval` legs.

For a direct smoke test:

```bash
npm run smoke -- "/absolute/path/to/vault" "your query"
```

See [README.md](README.md) for profiles and measured tradeoffs, and
[TROUBLESHOOTING.md](TROUBLESHOOTING.md) for model and fallback behavior.
